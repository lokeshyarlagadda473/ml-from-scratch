# ML From Scratch

Building machine learning from the ground up — no sklearn, no PyTorch internals. Pure NumPy and math.

## Why from scratch?
Understanding the math behind the models, not just calling APIs.
Each module is built, tested, then connected to the broader system.

## Modules
| # | Module | Status |
|---|---|---|
| 01 | Linear Algebra (vectors, matrices) | In Progress |
| 02 | Neural Networks (forward/backprop) | Not Started |
| 03 | Optimizers (SGD, Adam, RMSProp) | Not Started |
